# Fynza

This repository now includes a GitHub Pages-friendly root entry file at `index.html` so the app can be served directly from the repository root.

## Publish on GitHub Pages

1. Push this repository to GitHub.
2. Open the repository settings.
3. Go to Pages.
4. Set source to the default branch.
5. Use `/ (root)` as the publishing directory.

The root page is a clean static single-page dashboard designed to be lightweight and easy to maintain.
